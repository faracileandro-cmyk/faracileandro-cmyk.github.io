Drive Backup

App per Linux (Ubuntu/GNOME) che salva le tue cartelle sui servizi cloud: Google Drive, OneDrive, Dropbox e altri.

  • Backup manuali, programmati o in sincronizzazione
  • Impostazioni per tutti i backup o per singola cartella
  • Funziona sul tuo computer: i tuoi file vanno solo nel tuo cloud
