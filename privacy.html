Ultimo aggiornamento: 27 ottobre 2026

Dati raccolti

Aitna Backup funziona interamente sul tuo computer. Lo sviluppatore non raccoglie, non riceve e non conserva alcun dato personale né alcun file.

Accesso a Google Drive

Con il tuo consenso l'app usa l'autorizzazione drive, che dà accesso completo al tuo Google Drive. Serve per:

  • mostrarti nell'app tutti i file e le cartelle del Drive, come in un gestore di file;
  • salvare i backup, cioè creare e aggiornare i file e le cartelle che scegli;
  • creare, rinominare o eliminare file e cartelle solo quando lo fai tu dall'app. I file eliminati vanno nel cestino di Google Drive.

Queste informazioni vengono usate solo sul tuo computer, per mostrarti i tuoi file e gestire i backup. Non vengono inviate allo sviluppatore né a nessun altro.

I token di accesso sono salvati solo sul tuo computer. Puoi revocare l'accesso in qualsiasi momento dall'app (Impostazioni → Servizi cloud → Scollega) o da myaccount.google.com/permissions.

Condivisione

I tuoi dati non vengono venduti, condivisi o trasferiti a terzi. I file vengono inviati solo ai servizi cloud che scegli tu.

L'uso delle informazioni ricevute dalle API di Google rispetta le Google API Services User Data Policy, inclusi i requisiti di uso limitato.
